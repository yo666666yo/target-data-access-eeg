\begin{abstract}
Cross-subject EEG studies give held-out target-subject data different roles across protocols. An accuracy gap measures the performance gain attributable to using those target-subject trials only when other evaluation conditions are aligned; otherwise it may reflect differences in partitioning, sample exposure, model selection, or scoring. We partition each held-out subject's trials into available and reserved halves, score all conditions on the same reserved trials, and cross Euclidean Alignment with supervised training on the available half. The source split, per-epoch sample budget, early-stopping rule, target sampling rate, and realized indices are fixed. Across BCI Competition IV 2a, BNCI2014-002, and PhysionetMI, both procedures improve performance, but their ordering reverses across datasets. A no-retraining regrouping control shows that the standard deviation read as between-subject heterogeneity also changes with trials per group. Thus, target-data value and between-subject spread depend on dataset and evaluation design. Our code is available at \url{https://github.com/yo666666yo/target-data-access-eeg}.
\end{abstract}

dataset 2a, BNCI2014-002 and the PhysioNet EEG Motor Movement/Imagery database.
